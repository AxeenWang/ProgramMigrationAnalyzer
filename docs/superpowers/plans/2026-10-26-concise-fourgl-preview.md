# 大型報告預覽與精簡 4GL 說明實作計畫

目標是修正已重現的本機大型 HTML 載入失敗，並依本次人工與自動報告比較結果改善單檔離線報告。使用者已授權實作、驗證及重新發布測試 EXE。

## 範圍與設計

- 沿用目前功能分支與正式來源，不變動既有人工範例或客戶參考來源。
- WebView2 改讀取輸出區內、每個視窗各自擁有的 HTML 暫存檔，關閉後清理。初始化、寫檔與導航失敗分開記錄，載入失敗不永久停用所有後續預覽。
- 4GL 報告以用途、函式處理階段、條件後果、命令路由及欄位角色為正文。完整有效及停用 SQL 各保留一次，不複製整段 WHERE 當用途說明。
- 作者註解只挑選背景摘要，完整未知語法與診斷仍保留。宣告及重要資料流以緊湊表格呈現，不逐句重複全部賦值。
- 說明只能由同檔語句、SQL、使用位置及標示來源的註解推得，不硬編碼客戶、函式或欄位名稱，不新增 LLM、資料庫或套件。
- 外部命令變數採獨立有界候選容量，避免十多個路由就丟失 CASE 後最後命令。其他值維持既有上限。
