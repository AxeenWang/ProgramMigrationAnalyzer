# 專屬圖示與檔案勾選按鈕設計

使用者要求專屬程式圖示，並改善「全選 .4gl」與「全部取消」的外觀。沿用現有主題分支及全部未提交內容，不提交、推送、發布或安裝套件。

採用適合小尺寸的原創向量圖示，以程式括號與向右遷移箭頭表達程式移植分析，使用現有深藍、白色與青綠色。由相同向量來源產生多尺寸 Windows ICO，讓 EXE、視窗、工作列與自訂標題列有一致識別。保留可編輯的 WPF DrawingImage 來源及預覽，不依賴系統預設圖示或外部資產。

檔案勾選按鈕改用圓角、圖形與文字、淡藍及中性色，補上滑鼠懸停、按下、鍵盤焦點與停用狀態。保留 Content 文字及既有 ICommand，確保單一／全選／取消與數量提示不變，並維持最窄側欄可用。

向量原生方案較適合 16～256 像素的清晰度，也便於後續維護。圖示只在建置時嵌入，不增加客戶端檔案或連線需求。按鈕只調整樣式，不改變分析或批次邏輯。

圖示資產與樣式可平行處理，代理只能寫自己的資產與暫存範圍。完成後停止全部正式檔案寫入，執行建置、WPF 功能與排版檢查，擷取畫面並檢查 EXE 的實際圖示資源。
