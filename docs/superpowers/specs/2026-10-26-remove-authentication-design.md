# 恢復直接啟動

使用者要求先恢復開啟程式即可操作，完整移除目前登入、建帳與離線 Key 流程，以便客戶在內網部署。

## 行為與範圍

- 啟動直接建立並顯示分析主視窗，關閉主視窗即退出。
- 移除登入、登出、使用者顯示、授權匯入、帳密與簽章儲存、公司發證工具及公鑰發布依賴。
- 保留載入、分析、轉譯、報告、預覽、Diff、輸出與關閉時取消背景工作的保護。
- 客戶端維持 Windows x64 自包含單檔，發布不需 Key。HTML 預覽仍需 WebView2 Runtime。
- 不刪除工作區外的既有帳號、Key 或金鑰檔，不修改客戶環境。
- 現行文件改成直接操作。舊設計與交付紀錄保留為明確標示的歷史資料。

## 作法

完整移除認證元件及其依賴。只隱藏視窗或使用固定假帳號仍會保留部署負擔，不符合使用者要求。
直接沿用既有 WPF、MVVM 與各分析服務，不新增替代帳號或網路服務。

## 驗證

先以 WPF 啟動斷言重現登入門檻，再驗證無授權資料的直接啟動、原有畫面流程、文件釋放與輸出保留。
執行 Solution 建置、Phase2Checks、RegressionChecks、WpfChecks 與不帶公鑰的單檔發布驗證。
初次交付僅包含本機修改及驗證。2026-10-26 使用者已追加授權提交並推送本次功能移除與發布編碼修正，不建立 PR。
