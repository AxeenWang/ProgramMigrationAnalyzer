# 內嵌雜湊離線登入設計

## 已確認範圍

工具供擁有者在客戶封閉環境使用。使用者已確認本機實作與驗證，混淆只做相容性評估，不發布、不提交、不推送、不建立 PR、不合併或變更分支。

Active Target 為 `Projects/ProgramMigrationAnalyzer`，Target Lock enabled，CodeLab-managed。所有實作與建置均從正式專案根目錄進行。

## 方案比較

- 明文或可逆加密帳密容易連同程式被取得，不採用。
- 額外 Key 檔不符合這次交付限制，不恢復原先的匯入與公司發證流程。
- 採用內嵌帳號、salt、雜湊及參數，啟動後完全離線驗證。

## 驗證與建置

- PBKDF2-HMAC-SHA256，600,000 次迭代，16 bytes 隨機 salt，32 bytes 雜湊，固定時間比較雜湊。
- 帳號精確比對，密碼不修剪、不改變大小寫，最多 128 個 UTF-16 字元。
- 真實帳密不進入原始碼、測試、文件或 Git。忽略追蹤的 `config/embedded-login.json` 只保存驗證資料，建置時嵌入 App 資源，執行時不讀取外部設定。
- 建置缺少設定時失敗。執行時內嵌資料損壞則拒絕啟動，沒有預設密碼或免登入備援。
- 提供 PowerShell 遮罩輸入工具，用於本機產生或更換驗證資料。密碼不透過命令列、環境變數或檔案輸入。

## 登入與生命週期

- 每次啟動只顯示登入視窗，成功前不建立 MainWindow 或分析服務。
- 不記住密碼，不提供建帳、重設、Key 匯入或跳過登入參數。
- 未知帳號與錯誤密碼顯示相同提示，失敗後短暫延遲，防止快速連續嘗試。
- 驗證放在背景執行，禁止重複提交，取消與關閉立即清空密碼。晚到的驗證結果不得開啟主視窗。
- 登入成功只建立一個主視窗。關閉登入視窗或主視窗皆正常退出，保留既有分析成果。
- 不增加登出功能，不改動分析、轉譯、批次或報告的既有操作。

## 限制與驗收

雜湊保護密碼，不能阻止主機管理者修改程式或取得核心邏輯。離線環境無法即時撤銷已交付的舊 EXE。

先補啟動門檻的失敗測試，再實作驗證器、登入與建置設定。測試使用合成帳密與真正的 PBKDF2，不使用正式密碼。涵蓋錯誤帳密、空白與邊界、損壞設定、重複提交、取消、晚到結果及主視窗生命週期。

最終驗證前停止正式檔案寫入，建立雜湊快照，再執行 Solution build 與四組既有檢查。結束後比對正式檔案、本機驗證資料及既有發布 EXE 未在驗證中改變。

混淆只評估 WPF XAML/BAML、MVVM 綁定、source generator、JSON 與單檔打包的保留需求，不安裝工具，也不宣稱已完成混淆。
